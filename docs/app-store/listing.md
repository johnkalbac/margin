## Version information

**Promotional text (170).** Editable at any time without a new build.


**Description (4000).**

```
Margin is a calm, focused Markdown editor for the Mac. Write on the left and read the formatted result on the right. The two panes stay together as you scroll, line for line, even through long code blocks and tables.

No accounts. No sync. No tracking. Margin opens the files you choose, saves them where they were, and keeps nothing else.

WRITE AND PREVIEW
• Live split view with a draggable divider; focus either pane with one keystroke
• Scroll sync by source line, not percentage, so the panes never drift apart
• Syntax highlighting, including the languages inside fenced code blocks
• CommonMark, GitHub Flavored Markdown, or GFM with extras such as footnotes and definition lists
• Find and replace with regular expressions, case and whole-word matching

EVERY VERSION, KEPT
• Margin keeps an edit history for each file. Browse earlier versions, preview them, and restore any one. Restoring adds to the history rather than rewriting it, so nothing is lost by trying.
• Compare a document with another file or with an earlier version, shown inline.

YOUR FILES, RESPECTED
• Text encodings detected and preserved: UTF-8, UTF-16 and common legacy encodings
• Line endings kept exactly as they were
• A file changed on disk reloads automatically, or asks first if you have unsaved edits
• Optional auto-save, off until you turn it on

MADE FOR THE MAC
• Tabs you can reorder, or drag out into a window of their own
• A ⌘K command palette for everything in the menus
• Light and dark appearance
• Open Recent, and Open With from Finder for Markdown files

PRIVATE BY DESIGN
Margin collects no data. There are no analytics, no telemetry and no ads, and the app makes no network connections. Your documents never leave your Mac.
```

## App Review information

**Sign-in required:** No.

**Notes:**

```
Margin is a local Markdown editor. No account or sign-in is needed, and the app makes no network connections.

To try it: File > New, type some Markdown, and the preview updates on the right. File > Open opens any .md or .txt file. View > Toggle History shows the edit history of a saved file, and View > Compare With File shows an inline diff against another file.

The app is sandboxed and only accesses files the user picks in an Open or Save dialog. Security-scoped bookmarks let Open Recent reopen those files after relaunch.
```
